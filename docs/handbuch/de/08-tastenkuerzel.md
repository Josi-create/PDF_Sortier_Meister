# Tastenkürzel

Auf dem Mac steht `Cmd` statt `Strg`.

| Kürzel | Wirkung |
|---|---|
| `F1` | Handbuch öffnen |
| `F2` | Umbenennen |
| `F5` | Ansicht aktualisieren |
| `Strg+O` | Scan-Ordner öffnen |
| `Strg+Z` | Rückgängig |
| `Strg+A` | Alle markieren |
| `Esc` | Auswahl aufheben |
| `Entf` | Markierte Dateien in den Papierkorb |
| `Alt+↑` | Übergeordneter Ordner |
| `Alt+←` | Zurück |
| `Strg+F` | Dokumentensuche (Metadaten) |
| `Strg+Umschalt+F` | Reiter „Suche“ (Volltext) |
| `Strg+Q` | Beenden |
