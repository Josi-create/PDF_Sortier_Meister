# Stapeln, Trennen und Seiten

## PDFs stapeln

Wie in PaperPort: Ziehst du eine PDF auf eine andere, legt PDFSM sie **davor**, wie ein Blatt
auf einen Stapel. Die gezogene PDF wird Seite 1, die Ziel-PDF behält ihren Namen und Ort.
`Strg+Z` macht das Stapeln rückgängig.

## PDF trennen

- **Alle Seiten einzeln** oder einen **Seitenbereich** in eine eigene Datei herausnehmen.
- **KI-unterstütztes Trennen:** Ein Scan-Stapel mit mehreren Schriftstücken wird an den
  Dokumentgrenzen zerlegt. Für jedes Dokument gibt es einen Namensvorschlag und eine Vorschau,
  in der sich die Grenzen anpassen lassen.

## Seiten drehen und gerade ausrichten

- Über das Rechtsklick-Menü einer Kachel lassen sich Seiten **drehen**.
- **Rechtsklick › Drehen › „Gerade ausrichten“** richtet schief eingezogene Seiten gerade.
- Bei neuen Scans geschieht beides auf Wunsch von selbst (abschaltbar): Seiten, die auf dem Kopf
  stehen oder quer liegen, werden richtig herum gespeichert, schiefe Seiten gerade gerückt. Das
  Scanbild wird dabei nicht neu berechnet; vorher entsteht eine Sicherungskopie.

## Textebene

Gescannte PDFs ohne Text bekommen auf Wunsch den erkannten Text als **unsichtbare Ebene**
(abschaltbar). Dann finden auch der Explorer, Acrobat und andere Programme den Text. Das Scanbild
bleibt unverändert, vorher entsteht eine Sicherungskopie, und jede Änderung lässt sich rückgängig
machen.
