# AI providers

AI is **optional**. Without AI, PDFSM sorts with a local, learning classifier that works offline.
With AI, folder and name suggestions get better, metadata fills itself in, and there is the chat.
The local classifier always comes first; the AI is only asked when it is unsure.

Everything is set under **Settings › AI assistant (LLM)**.

## The providers

| Provider | Runs where | Note |
|---|---|---|
| **Ollama** | on your computer | no API key, starts by itself when needed |
| **Ollama Cloud** | on ollama.com | the same models, for computers without a graphics card |
| **OpenRouter**, **Anthropic Claude**, **OpenAI**, **Poe** | in the cloud | API key required |

The setup wizard checks the graphics card and recommends a suitable local model (depending on
graphics memory) or, without a dedicated graphics card, Ollama Cloud. It detects an existing
Ollama installation, shows the installed models and downloads the recommended model with one
click.

## Local AI with Ollama

- On the **first call after start**, Ollama first loads the model into memory. This takes one to
  two minutes; the status bar and the chat then say that the model is loading.
- **Double-clicking the status bar** opens the "Background analysis" window. If the configured
  model is missing, it lists the installed models and switches to one at the click of a button.
  If Ollama is not running, there is a "Start Ollama" button.
- In the settings, the model choice lists the installed models. A saved model that no longer
  exists is shown in red as not installed.

## Privacy

| Setting | What leaves the computer |
|---|---|
| No AI (default) | nothing |
| Ollama (local) | nothing |
| Cloud providers | a **text excerpt** of the PDF (adjustable from 500 to 5000 characters, default 1500), only after explicit consent in the settings. The PDF file itself is never uploaded. |
| Document search, browser interface | nothing |
| AI assistant via MCP | whatever the assistant queries goes to its provider |

There is no telemetry.
