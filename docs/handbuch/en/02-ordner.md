# Scan folder and target folders

## Scan folder

The scan folder is the inbox: this is where the scanner puts new PDFs. PDFSM shows it on the left
like a file manager.

- **Change the scan folder:** **File › Open scan folder...** (`Ctrl+O`) or the "Scan folder"
  button in the toolbar.
- **Subfolders** appear as tiles; double-click opens them. The path bar takes you back, as do
  `Alt+↑` (parent folder) and `Alt+←` (back).
- **Tile size:** small, medium or large as in Explorer. Small tiles show a large preview on
  hover.
- **New scans** appear as tiles by themselves. `F5` refreshes the view manually.
- **Start from Explorer (Windows):** right-click a folder or a PDF and choose the PDF Sortmeister
  entry to open the program right there.

## Scan now

The **"Scan now"** button in the toolbar starts your scanning program. You set it under
**Settings › General › Scanning**; the "Suggestions" button lists the scanning programs found on
the computer. The field "New scans are saved in:" holds the folder your scanning program saves
to. When the new scan appears, it is selected and shown right away.

Scanning itself happens in the scanning program. Any program that saves PDFs into a folder
works.

## Target folders

Target folders are the folders you sort into. They are on the right.

- **Add:** **File › Add target folder...** or the "+ Target folder" button.
- **Suggestions:** PDFSM reads the content of the PDF and highlights matching target folders in
  green. It learns from each of your decisions. If it finds a year in the document, it offers
  e.g. `Taxes 2026/Receipts` next to `Taxes 2025/Receipts`.
- **Last moved to:** The **View** menu lists the folders you moved to most recently.

## Managing files

- **Multiple selection** with `Shift`- or `Ctrl`-click, select all with `Ctrl+A`, clear the
  selection with `Esc`.
- **Drag and drop:** PDFs can be dragged onto a target folder.
- **Delete:** `Del` moves the selected files to the Recycle Bin.
- **Undo:** `Ctrl+Z` takes back the last action, e.g. moving, renaming or stacking.
- **Duplicate files:** **Tools › Find duplicate files …** finds identical files.
