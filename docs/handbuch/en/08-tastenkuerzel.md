# Keyboard shortcuts

On the Mac, use `Cmd` instead of `Ctrl`.

| Shortcut | Action |
|---|---|
| `F1` | Open the manual |
| `F2` | Rename |
| `F5` | Refresh view |
| `Ctrl+O` | Open scan folder |
| `Ctrl+Z` | Undo |
| `Ctrl+A` | Select all |
| `Esc` | Clear selection |
| `Del` | Move selected files to the Recycle Bin |
| `Alt+↑` | Parent folder |
| `Alt+←` | Back |
| `Ctrl+F` | Document search (metadata) |
| `Ctrl+Shift+F` | "Search" tab (full text) |
| `Ctrl+Q` | Quit |
